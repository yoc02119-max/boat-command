# BOAT COMMAND v0.9.2 — DATA INTEGRITY

STRICT BACKTESTの時刻整合性ガードを追加。

重要修正:
v0.9.1の1R気象欄は、BOAT RACE公式「直前情報」アーカイブ上で
20:44現在の値に更新されていた。一方1R締切は15:21。
そのため、結果そのものではないが「1R予想時点より後の情報」であり、
STRICT BLINDの入力として不適格と判定して除外した。

v0.9.2:
- 1Rの選手/級別/平均ST/勝率/モーター/展示タイム/展示STは維持
- 時刻が締切後の気象値は非表示
- TIME-SAFEバッジを追加
- 今後のFULL SNAPSHOTでも「項目の値」だけでなく「その値がいつ時点か」を監査
- 締切より後の更新値は予想入力に使用しない

精度検証では、欠損値を推測で埋めない。
